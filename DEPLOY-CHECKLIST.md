# FoodFit — checklist перед публикацией

- [ ] Открыть `index.html` локально и проверить генерацию недельного плана.
- [ ] Проверить мобильный вид страницы.
- [ ] Проверить «Заменить» и открытие рецепта.
- [ ] Проверить аллергены и строгие исключения.
- [ ] Проверить режимы бюджета и разнообразия покупок.
- [ ] Проверить список покупок.
- [ ] Опубликовать через HTTPS.
- [ ] Открыть публичную ссылку в приватном окне браузера.
- [ ] Пройти onboarding как новый пользователь.
- [ ] Проверить сайт на телефоне.
- [ ] Дать ссылку первым 5–10 тестировщикам.
