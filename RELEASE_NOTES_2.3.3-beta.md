Hotfix-релиз.

Исправлена критическая ошибка предыдущей версии, из-за которой JavaScript не инициализировался и не работали:

- «Применить»;

- другие интерактивные кнопки.

Также окончательно удалены остатки функции замены отдельных ингредиентов внутри рецептов.
