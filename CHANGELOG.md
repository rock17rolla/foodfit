# Changelog

## [2.5.1-beta] - 2026-08-24

### Added
- Сводный блок «Баланс за N дней».
- Общие показатели калорий, БЖУ и клетчатки за весь период.
- Отображение процентов калорийности каждого дня.
- Примерное количество штук непосредственно в ингредиентах рецепта.

### Changed
- Планирование на несколько дней теперь балансируется как единый период.
- Отдельные дни могут немного отклоняться от 100%, чтобы итог периода был ближе к целевой калорийности.
- Названия автоматически созданных рецептов приведены в соответствие с фактическим составом.

### Fixed
- Исправлены некорректные названия рецептов после расширения каталога в 2.4.
- Исправлена критическая ошибка инициализации JavaScript.
- Восстановлена работа расчётного ориентира и интерактивных кнопок.
- Исправлено отображение блока «Баланс за N дней».
- Исправлена позиция блока сводки внутри сформированного рациона.

## [2.4.0-beta]

Последний ранее опубликованный Beta-релиз.
Крупное обновление каталога рецептов и системы разнообразия блюд.
