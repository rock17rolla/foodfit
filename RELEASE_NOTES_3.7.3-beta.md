# FoodFit 3.7.3 Beta — QA Quarantine Hotfix

## Удалён проблемный рецепт
Рецепт **«Яичный тост с огурцом»** полностью удалён из базы и больше не может появиться в рационе или через замену блюда.

Причина: рецепт демонстрировал несколько противоречий одновременно — несоответствие отображаемого белка ожидаемому составу и неполную технологию приготовления.

## Master QA quarantine
Добавлен новый итоговый статус `masterQAStatus`.

Если рецепт одновременно проваливает минимум две независимые QA-проверки, он автоматически получает:

`masterQAStatus = quarantined`

и исключается:
- из генерации рациона;
- из функции «Заменить рецепт».

Это предотвращает ситуацию, когда потенциально повреждённый рецепт продолжает попадать пользователям после нескольких автоматических преобразований.
