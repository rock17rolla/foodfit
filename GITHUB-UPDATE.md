## Рекомендуемый порядок

1. Загрузить `index.html`, `CHANGELOG.md` и сопутствующие файлы в `main`.
2. Дождаться обновления GitHub Pages.
3. Проверить опубликованный сайт в приватном окне.
4. Проверить:
   - расчётный ориентир;
   - генерацию 7-дневного рациона;
   - блок «Баланс за 7 дней»;
   - открытие рецепта;
   - количество продуктов в штуках;
   - список покупок.
5. После проверки создать tag `v2.5.1-beta`.
6. Создать GitHub Release с названием `FoodFit 2.5.1 Beta — Period Balance`.
