# FoodFit 3.0 Beta — Scenario Coverage Expansion

Целевое расширение каталога после сценарного QA.

## Что добавлено
- 39 новых рецептов, подобранных специально под слабые сценарии.
- Быстрые обеды и ужины до 10 минут.
- Бюджетные вегетарианские блюда.
- Бюджетные безлактозные блюда.
- Бюджетные блюда для режима «меньше газообразующих продуктов».
- Дополнительные простые перекусы для ограниченных сценариев.

## Почему это важно
Рецепты добавлялись не ради общего числа, а для увеличения реального пула выбора там, где генератор раньше быстро начинал повторяться.

## QA
После расширения повторно проверены проблемные комбинации по типу рациона, бюджету и времени приготовления.
Сценариев с пулом меньше 8 рецептов на тип приёма пищи осталось: 0.
