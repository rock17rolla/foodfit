# FoodFit 3.1 Beta — Adaptive Cooking Methods

## Интерактивные способы приготовления
В карточке рецепта доступные способы приготовления теперь являются кнопками.

- Самый быстрый доступный способ выбирается по умолчанию.
- Пользователь может выбрать другой доступный способ.
- Выбранный способ подсвечивается.
- Метка «быстрее всего» остаётся у действительно самого быстрого метода.
- Время в верхней части рецепта обновляется вместе с выбранным способом.

## Адаптивное приготовление
Раздел «Приготовление» автоматически перестраивается под выбранную технику.

Поддерживаются отдельные технологические инструкции для:
- сковороды;
- мультиварки;
- духовки;
- аэрогриля;
- микроволновки;
- блендера;
- блюд без техники.

Алгоритм учитывает фактический состав рецепта: мясо, рыбу, птицу, тофу, яйца, крупу, картофель, овощи и соусы.

Микроволновка не описывается как способ приготовления сырой курицы, мяса или рыбы с нуля: если такой рецепт допускает микроволновку, инструкция ограничивает её роль разогревом или приготовлением гарнира/овощей.
