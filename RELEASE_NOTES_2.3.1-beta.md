# FoodFit 2.3.1 Beta

Небольшое обновление по итогам первого пользовательского тестирования.

## Изменено

- Добавлены периоды планирования **3 дня** и **5 дней**. Теперь доступны 1, 3, 5 и 7 дней.
- Диапазоны настройки «Разнообразие покупок» теперь видны прямо в списке: **Широкое (22–30 продуктов)**, **Среднее (16–22 продукта)**, **Минимальное (10–14 продуктов)**.
- Удалена автоматическая замена отдельных ингредиентов внутри рецепта. Тестирование показало, что такая замена иногда нарушала кулинарную логику блюда.
- Функция **замены блюда целиком** сохранена.

## Почему убрана замена ингредиентов

Для FoodFit важнее гарантировать рабочий рецепт, чем предлагать формально похожий ингредиент, который может не подходить конкретному блюду. В будущем эту функцию стоит возвращать только через заранее проверенные замены для каждого рецепта.
