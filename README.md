# FoodFit 2.3 Beta — static web release

Это готовая статическая версия FoodFit. Для работы сайта не нужны Node.js, сервер или база данных.

## Локальный запуск

Откройте `index.html` двойным кликом.

## Самый простой публичный запуск — Netlify Drop

1. Откройте Netlify.
2. Выберите ручную загрузку сайта / drag-and-drop deploy.
3. Перетащите всю папку `foodfit-web-ready`.
4. После публикации Netlify выдаст публичный HTTPS-адрес.

## Vercel

1. Создайте новый проект.
2. Загрузите эту папку или репозиторий GitHub с её содержимым.
3. Framework Preset: `Other`.
4. Build Command: оставить пустым.
5. Output Directory: `.`
6. Deploy.

## GitHub Pages

1. Создайте новый GitHub-репозиторий.
2. Загрузите содержимое этой папки в корень репозитория.
3. Settings → Pages.
4. Source: `Deploy from a branch`.
5. Branch: `main`, folder: `/ (root)`.
6. Сохраните. Через некоторое время появится публичная ссылка.

## Важно

FoodFit 2.3 Beta хранит настройки пользователя в `localStorage` браузера. Они не синхронизируются между устройствами и браузерами.

Для первой закрытой беты этого достаточно. Перед масштабным публичным запуском стоит перейти на аккаунты и серверное хранение.
