# FoodFit 2.3.2 Beta

Обновление по итогам пользовательского тестирования.

## Исправлено
- Проведён аудит рецептов, где была указана микроволновка.
- Микроволновка удалена из рецептов с курицей, индейкой, мясом, рыбой, креветками и другими блюдами, где готовка с нуля таким способом неуместна.
- Пошаговые инструкции больше не должны противоречить доступному способу приготовления.

## Список покупок
- Покупки сгруппированы по категориям.
- Для продуктов, которые обычно покупают поштучно, рядом с граммовкой показывается приблизительное количество штук.
- Количество округляется до шага 0,5.

## Техническая проверка
- Удалено сомнительных microwave-вариантов: 14.
- Оставлено уместных microwave-вариантов: 18.
