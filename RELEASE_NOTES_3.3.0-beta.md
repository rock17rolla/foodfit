# FoodFit 3.3 Beta — External Culinary Validation

## Полный кулинарный validation gate
Все 363 рецепта прошли повторную классификацию по технологии блюда и были сопоставлены с внешним кулинарным прототипом из Good Food, The Kitchn или EatingWell.

Рецепт допускается генератором только при статусе `verified`. Если в будущем новый рецепт не имеет проверенного технологического класса или не проходит его обязательные условия, он получает `quarantined` и не должен попадать в рацион.

Текущий результат:
- verified: 363;
- quarantined: 0.

## Техника теперь подчиняется технологии блюда
- Творожные овсяные панкейки требуют блендер для подготовки теста и сковороду для жарки.
- Смузи готовятся в блендере.
- Чиа-пудинги требуют замачивания/охлаждения, а не нагрева.
- Йогуртовые и творожные боулы не получают мультиварку или духовку.
- Паста готовится на плите; аэрогриль больше не подменяет варку пасты.
- Сырая птица, мясо и рыба не получают микроволновку как полноценный способ приготовления.
- Для каш фрукты, ягоды, йогурт и орехи добавляются после приготовления крупы.
- Для тостов сначала готовится хлеб, затем холодная начинка.

## Внешние источники
В архив включены:
- `EXTERNAL_RECIPE_VALIDATION.csv` — статус и внешний прототип для каждого рецепта;
- `CULINARY_SOURCE_LIBRARY.csv` — библиотека источников, по которым валидируются технологические классы.
